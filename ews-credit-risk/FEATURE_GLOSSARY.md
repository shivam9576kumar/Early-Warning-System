# Feature Glossary — All 64 Financial Ratio Features

> These are the 64 features used by the EWS Credit Risk model.
> When preparing your CSV, use column names `Attr1`–`Attr64` or `X1`–`X64`.

| # | Column Name | Financial Ratio | Formula |
|---|-------------|-----------------|---------|
| 1 | Attr1 / X1 | Net Profitability | Net profit / total assets |
| 2 | Attr2 / X2 | Leverage Ratio | Total liabilities / total assets |
| 3 | Attr3 / X3 | Working Capital Ratio | Working capital / total assets |
| 4 | Attr4 / X4 | Current Ratio | Current assets / short-term liabilities |
| 5 | Attr5 / X5 | Defensive Interval | [(Cash + ST securities + receivables − ST liabilities) / (operating expenses − depreciation)] × 365 |
| 6 | Attr6 / X6 | Retained Earnings Ratio | Retained earnings / total assets |
| 7 | Attr7 / X7 | EBIT to Assets | EBIT / total assets |
| 8 | Attr8 / X8 | Equity to Debt | Book value of equity / total liabilities |
| 9 | Attr9 / X9 | Asset Turnover | Sales / total assets |
| 10 | Attr10 / X10 | Equity Ratio | Equity / total assets |
| 11 | Attr11 / X11 | Adjusted Profit to Assets | (Gross profit + extraordinary items + financial expenses) / total assets |
| 12 | Attr12 / X12 | GP to ST Liabilities | Gross profit / short-term liabilities |
| 13 | Attr13 / X13 | Cash Margin | (Gross profit + depreciation) / sales |
| 14 | Attr14 / X14 | EBIT+ to Assets | (Gross profit + interest) / total assets |
| 15 | Attr15 / X15 | Debt Coverage Days | (Total liabilities × 365) / (gross profit + depreciation) |
| 16 | Attr16 / X16 | Debt Service Capacity | (Gross profit + depreciation) / total liabilities |

---

## Notes

- **Missing values are acceptable**: Use `NaN`, blank cells, or `?`
- **Feature order matters**: Columns should be in the order Attr1–Attr64
- **Scaling**: Not required — the model handles raw ratios
- **Negative values are OK**: Many ratios (e.g., net profit) can be negative for distressed firms
